## 🏠 Homelab : mon serveur auto-hébergé

> Depuis septembre 2025, je fais tourner ma propre infra sur **navilink.fr**, pour garder le contrôle de mes données.

- 🖥️ **VPS sous Debian 13 (Trixie)**, avec tous les services conteneurisés sous **Docker**
- 📬 **Serveur mail**, 🔐 **VPN** et 🔑 **gestionnaire de mots de passe**
- 🦖 **Pterodactyl** pour déployer mes APIs et serveurs ([image Docker maison](https://github.com/Legambey/playwright-uvicorn-chromium))
- 🛡️ Configuration du **pare-feu**, **durcissement** des services et lecture des **journaux** pour diagnostiquer les incidents
